== 色彩階層の基本原則

.主要トークンと役割
[cols="2,2,3", options="header"]
|===
| 色名 | HEX | 主な適用先
| 白鼠 | `#dcdddd` | 本文、標準テキスト
| 舛花色 | `#567a98` | 予約語、制御構文
| 江戸茶 | `#cd8c5c` | 文字列、リテラル
|===

TIP: 波長が揃った色を採用することで、長時間の閲覧でも毛様体筋の緊張を防ぎます。

[source,typescript]
----
const themeStatus: string = "active";
console.log(`Status: ${themeStatus}`);
----
