# 錦秋の江戸鼠テーマ（H1: 江戸茶）

## 光学と色彩設計の基本（H2: 丁子茶）

これは**太字テキスト（強調）**と*斜体テキスト*、および `const inlineCode = "#dddcd6"` のテストです。

### リンクと引用（H3）

> この引用文は老竹色や薄墨色のトーンで静かに表示されるべきエリアです。
> ピントを邪魔しない落ち着いた表示が求められます。

詳細な仕様は [公式リファレンス](https://example.com/edo-nezu/specification) または [リポジトリ](https://github.com/) を参照してください。

---

### 設計方針と構造一覧（リスト検証用）

#### 1. 記号リスト（3段階ネスト）

- 背景と土台の設計
  - 憲法黒茶をベースとした暗所環境
    - 濡れ縁や庭石のような深い陰影の形成
    - 瞳孔を開かせない低刺激な黒レベル
  - サイドバー・ステータスバーの階層分離
- 前景とアクセントの配置
  - 枯山水の白砂を模した白灰の基本テキスト
    - エディタ本文
    - 各種データ構造キー

#### 2. 番号付きリスト（3段階ネスト）

1. 配色パレットの選定工程
   1. 四十八茶百鼠から基本色を抽出
      1. 青丹・老竹色（緑系）の決定
      2. 牡丹鼠（赤紫灰系）の決定
   2. コントラスト比の検証
2. VS Code 構文スコープへのマッピング
   1. TextMate スコープの最適化
   2. セマンティックトークンの固定

#### 3. 複合ネスト（記号 × 番号）

- 第一階層：テーマの最適化対象
  1. 第二階層：プログラムソース（TypeScript / Java / Python）
     - 第三階層：予約語・リテラル・コメント
     - 第三階層：クラス名・メソッド名
  2. 第二階層：設定ファイル（JSON / YAML / XML）
     - 第三階層：キー・タグ・属性名
